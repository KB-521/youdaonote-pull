fs: 文件管理

```javascript
fs.readFile //读
fs.writeFile //写
//注: node任何方法都有同步和异步两套
//node里不要用相对路径要使用绝对路径
```



path: 路径

```javascript
path.resolve(__dirname, '../1.txt') 
//将相对路径变成绝对路径
```
