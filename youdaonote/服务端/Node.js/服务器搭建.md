原生http模块获取静态文件麻烦，if else 过多维护成本高



几款node服务端框架：

```javascript
express
koa
next.js react 服务端框架
nuxt.js vue 服务端框架
nest.js angular 服务端框架
ngins //配置形式服务器 -> 静态文件服务器 || node服务器  较多使用
```



express框架设置服务器：

```javascript
const app = express()
app.use((req,res,next) => {}) //中间件处理
app.use(cors()) //cors插件设置跨域
app.use(express.static(path.resolve(__dirname, "../static"))) //自动加载静态文件
app.get("路径", (req, res)=>{
  //处理 返回
})
app.listen(3000)
```
