安装：

```typescript
npm i -g @nestjs/cli
nest new project-name
```



热更新：

```typescript
yarn start:dev
```



新增模块：

```typescript
nest g mo name //在src下新增name.module文件
nest g co name // 在src下新增name.controller文件
nest g s name // 在src下新增name.service文件
// 以上都可以在最后加上指定文件夹名称
// 注: 尽量先创建module文件, 先创建module会自动注入app.modules.ts，避免重复引入增量模块
```



配置全局路由：

```typescript
//在main.js入口文件里加入
app.setGlobalPrefix('全局路由名称');
```
