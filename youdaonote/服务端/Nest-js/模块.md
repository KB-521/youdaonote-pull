nest核心概念：

1. Controller: 传统意义上的控制器，提供api接口，负责处理路由、中转、验证等一些简洁的业务。

```typescript
// 获取前台传入的值
@Query(){ id } 
@Headers('token'){ token }
@Body(){ message }
@Param(){ id } //在url/后面的字符
```

1. Service：又称为 Provider， 是一系列服务、repo、工厂方法、helper 的总称，主要负责处理具体的业务，如数据库的增删改查、事务、并发等逻辑代码.

1. Module：负责将 Controller 和 Service 连接起来。

```typescript
// API
imports: 依赖注入
```
