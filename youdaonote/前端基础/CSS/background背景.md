平铺:

```css
background-repeat:repeat/repeat-x/repeat-y/no-repeat;
```



移动:

```javascript
background-position:x y; // 像素/百分比
```



固定:

```css
background-attchment:fixed;
background:color image repeat attchment position;
```



指定绘制背景图像时的起点：

```javascript
background-origin:border-box(默认)/padding-box/content-box;
```



指定背景的显示范围：

```javascript
background-clip:border-box(默认)/padding-box/content-box;
```



指定背景中图像的尺寸：

```javascript
background-size:auto/length/percentage/cover/contain;
//cover:用一张图片铺满盒子;
//contain:让盒子保留一张完整背景图片;
```
