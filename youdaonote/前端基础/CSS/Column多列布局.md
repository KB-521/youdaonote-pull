多列布局：

```javascript
columns: cloumn-width column-count;
column-width: 每列的宽度;
column-count: 显示的列数;
column-gap: 列宽，默认由font-size决定;
column-rule:column-rule-width column-rule-style column-rule-color; //列边框样式
column-span:none/all; //默认/横跨所有列
```
