伪元素 清理浮动和margin：

```javascript
.class::before, .class::after{
    content:"";

}

    clear:both;
}
```

```javascript

```




垂直方向的margin父元素和子元素共用较大的一个，margin塌陷：

弥补方法:改变父级的渲染规则BFC（Block Format Context）；



BFC（块级格式化上下文）：

页面上的一个独立的渲染区域，让处于bfc内部的元素与外部的元素相互隔离，使内外元素的定位不会相互影响。

触发条件：position: absolute/fixed、display: inline-block / table、float、overflow !== visible。

作用：阻止margin重叠，清除内部浮动，自适应两栏布局，阻止元素被浮动元素覆盖。
