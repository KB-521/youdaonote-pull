事件源：产生事件的地方；

事件的类型：点击、键盘...；

事件的对象：记录好的信息；

事件的处理方式：函数；



添加事件：

```javascript
.addEventListener(事件类型(click), 函数, 事件的处理方式(false:冒泡,turn:捕获));
```

删除事件：

```javascript
.removeEventListener(事件类型(click), 函数, 事件的处理方式(false:冒泡,turn:捕获));
// 注: 函数必需是指向同一个地址, 不然没有效果.
```



事件函数：当事件发生时所执行的函数；



event（事件对象 ）：提供了事假的详细信息；(ie8之前通过window.event)



取消默认操作：

```javascript
event.preventDefault();
```



调用HTML元素取消默认操作：

```javascript
return false; (ie8之前event.returnValuefales;）
```



在默认的情况下，点击页面的一个标签，处在传播路上的标签都会监听的到对应事件；



事件流：

捕获阶段：起始点->目标点；冒泡阶段：目标点->起始点；



终止冒泡阶段：

```javascript
event.stopPropagation();
```
