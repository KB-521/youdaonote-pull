当前对象：本地属性、私有属性；

原型对象：原型属性、公共属性；

本地属性被修改，只有当前对象的该属性被修改；

原型属性被修改，只有对象的该属性被修改；



继承的原则：1.本地有的用本地；2.本地没有的找原型；3.原型没有的找原型对象的原型；（原型链）

```javascript
 Object.getPrototypeOf(对象);  //可以查找原型对象指针
 构造函数.isPrototypeOf(对象); //构造函数检测原型
 for/in -> 可枚举属性，包括原型的属性
 对象.hasOwnProperty(属性名); //检测私有属性
 Object.getOwnPropertyNames(对象); //获得对象所有私有属性名称
 Object.keys(对象); //获得对象可枚举的私有属性的名称
```



原型：

- 每个函数都有prototype属性，这个属性指向一个对象。

- 每个对象创建的时候都有__proto__属性，指向创建了该对象的构造函数的prototype。其实这个属性指向了[[prototype]]，但是[[prototype]]是内部属性，无法访问到，所以使用__proto__来访问。

- 注：__proto__设计时也是一个内部属性，只是浏览器厂商给暴露出来了。getPrototype和setPrototype才是规范属性，等于__proto__。

- 对象可以通过原型来寻找不属于该对象的属性，如果这个对象内部不存在这个属性，那么他就会去原型里去寻找这个属性，这个原型又有自己的原型，于是就这样一直寻找下去，这就是原型链。

new到底做了什么：

- 创建一个空对象，并且this变量引用该对象，同时还继承了该函数的原型。

- 属性和方法被加入到this引用的对象中。

- 新创建的对象由this所引用，并且最后隐式的返回this。

```javascript
//new
function create(){
    // 创建一个空对象
    let obj = new Object()
    // 获得构造函数
    let Con = [].shift.call(arguments)
    // 连接到原型
    obj.__proto__ = Con.prototype
    // 绑定this,执行构造函数
    let result = Con.apply(obj, arguments)
    // 确保 new 出来的是个对象
    return typeof result === 'object' ? result : obj
}

// 定义一个构造函数
function Foo(name,age){
    this.name = name;
    this.age = age;
}

create(Foo, 'king', 20) === new Foo('king' , 20)
```
