意义：描述字符定义模式的对象，字符组成的特殊格式的字符串;

定义：直接量 ->  /字符模式/标志字符；RegExp类；

标志字符：g -> 全匹配；i -> 不分大小写；m -> 多行匹配；

组成：普通字符（A~Z a~z 0~9 + - * / () {} * ?  =   ^等等）及元字符；

字符模式[ ]里可以拼接；

"?:"：非匹配获取，只匹配内容，不保存;

作用：1.验证字符串；2.查找字符串；3.截取字符串；4.替换字符串；

```javascript
\w -> a-z A-z 0-9 _
```



使用正则表达式匹配：

```javascript
RegExp.exec(string); //返回特定数组
//string: 匹配的字符
RegExp.test(string); //返回true/false
```
