万物皆对象；

- 类是一个设计概念，对象是实际物体；

- 对象概念：存在内存中，可以具有多个属性的数据；

- 对象 = 一堆变量 + 一堆函数的集合；

- 获取属性值用“点”，多层级的，就用多个点。

- 对象属性名会被隐式的转换为string，包含了特殊字符要加上引号；

- 对象可以通过 . 或者 [ ] 的形式获取对象的属性，不用加引号的属性名才能用 . 的形式获取对象的属性；

- 对象如果修改属性的时候没有这条属性，自动增加；

- 删除：delete加属性名，并不是完全删除而是将他们的联系断开，删除后的属性还存在；



对象拷贝:

```javascript
var obj2 = obj1; //这样只是把obj1指向堆的地址复制给了obj2，
//obj2修改了某值，obj1也会对应修改;
```

```javascript
//枚举法拷贝对象
var o ={};
for(var i in obj){
    o[i] = obj[i];

```

对象销毁机制：无引用后定期自动回；

对象创建方式：

```javascript
var a1 = {};  //直接量
var a1 = new A(); //构造函数类
var a1 = Object.create(原型对象，属性列表); //create方法
```

创建原理：基于构造函数定义的属性，并继承原型对象的属性，生成一个新的对象；

```javascript
var objectProto = {name1:value1,name2:value2};
Object.prototype = objectProto;
//另一种方法,效果相等
Object.prototype.name1 = value1;
Object.prototype.name2 = value2; 
```



# 对象属性特性

```javascript
Object.defineProperty(对象,属性名字符串,(描述特性对象){
    value:值,
    writable:true, //可写 ->是否可设置该属性的值
    enumerable:true, //可枚举 ->for/in是否可获得该值
    configurable:true, //可配置 ->是否可删除或修改该属性的特性
})
```

```javascript
Object.defineProperties(对象,{
    属性名字符串1:{
        value:值, 
        writable:true, //是否可以修改
        enumerable:true, //是否可枚举
        configurable:false, //是否可配置
    },
    属性名字符串2:{
        value:值,
        writable:false, //是否可以修改
        enumerable:true, //是否可枚举
        configurable:true, //是否可配置
    }})
```

```javascript
Object.getOwnPropertyDescriptor(对象,属性名) //查看属性的特性
```

# 原型

![](images/C41EDB333D37477D8A7269C192FAB111jpg)

原型属性被修改，所有对象的该属性被修改



prototype, __proto__,constructor之间的关系：

```javascript
每次创建一个函数都会按照特定的规则为他创建一个prototype属性，它指向函数的原型对象。
所有的原型对象自动会获得一个constructor属性，他指向与之关联的构造函数。
每次调用构造函数创建新实例时，这个实例内部的[[prototype]]指针就会赋值为构造函数的原型对象。
脚本中没有访问这个[[prototype]]特性的标准方式，Firefox、Safari 和 Chrome会暴露出__proto__属性用来访问对象的原型。
实例和构造函数并没有直接联系，他们都和原型对象存在这联系。
prototype属性是函数所独有的，因为函数也是一种对象，所以函数也有__proto__和constructor属性。
当一个我们访问一个对象属性时，如果对象内部不存在这个属性，那他就回去对象的__proto__所指向的原型对象上去找，一直找到最顶层的null为止。
通过__proto__属性将对象连接起来的这条链路即我们所谓的原型链。
```
