注意看看ES5中的数组方法，ES5中有很多实用方法，与ES6方法结合使用；



创建数组：

```javascript
Array.of(num); //创建一个具有单个元素num的数组
Array.from(arrayLike,Fun); 
//从一个类似数组或可迭代对象arrayLike创建一个新的，浅拷贝数组
//Fun: 可选,数组中每个元素都会执行的回调函数
```



数组方法：

```javascript
.find/findindex(function(item,index,arr){});
//给每个元素都执行一次function,返回第一个带true的元素,否则返回undefined
.fill(str,start,end);
//给数组里从(start,end)的元素变成str,
.copyWithin(num,start,end);
//复制数组的元素,从num开始,复制的区域(start,end);
.some(Fun(arg){}); //如果数组里有一个数符合回调函数的比较式就返回true
.some(Fun(arg){}); //如果数组里全部的数符合回调函数的比较式就返回true
.includes(num)； //查看数组里有没有等于num的值,有则返回true
//注: 可以判断NaN,但无法区分+0、-0
.flat(depth) // 按照一个可指定深度递归数组，并将所有数组与遍历到的子数组合并为一个新数组返回。
// 注: depth = 指定递归深度，写入Infinity可以去全部展开
```





为什么 for 循环的性能高于 forEach 的性能：

- for 循环没有任何额外的函数调用栈和上下文；

- forEach函数签名实际上是

```javascript
array.forEach(function(currentValue, index, arr), thisValue)
```

它不是普通的 for 循环的语法糖，还有诸多参数和上下文需要在执行的时候考虑进来，这里可能拖慢性能；
