ES6对象定义：

```javascript
let obj = {
    show(){表达式},
    ect: () => {表达式}，
}
//两种方法都可以定义对象，不过要注意两种方法的this指向时不同的
//第一种只是function的简写，所以this指向和function一样
```



用 [属性名] 方式可以直接调用属性对应的参数来当做对象名，也可以在里面写表达式运算；



方法：

```javascript
Obejct.is(a,b); //比较两个参数是否全等
//与===相比: is()可以判断两个NaN、-0 +0的区别

Object.setPrototypeOf(obj,obj1); //把obj1的值复制到obj的原型中去
//与Object.create()相比: 可以多次调用
//__proto__不在ES的标准内,尽量不要调用;
Object.getPrototypeOf(obj); //查看对象的全部原型属性

Object.assign(目标对象，...源对象); //把全部的源对象都复制到目标对象中去
//注:1.只复制源对象的属性,源对象原型属性不会复制
//2.属性可遍历的才会被复制
//3.复制对象是按顺序一个个复制的,同名属性会被后面的覆盖
//4.浅拷贝

Object.keys(obj); //取出obj所有键名,es6
Object.values(obj);  //取出obj所有键值,es7(2018)
Object.entries(obj); //取出obj所有键值对,es7(2018)
```
