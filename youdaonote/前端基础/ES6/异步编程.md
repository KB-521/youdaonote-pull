1. 同步编程：

问题：不合理的模式，会阻塞代码的执行；

好处：代码非常容易理解；



1. 回调函数：

```javascript
setTimeout(() => { 
    //callback 函数体
}, 1000)
```

问题：回调地狱，控制反转（函数存在耦合性，牵一发动全身），代码没有同步好理解；

好处：解决了同步的问题，和浏览器交互，能调用浏览器许多强大的API；



1. Promise：

问题：没有很好的解决异步流程，无法取消Promise，错误需要通过回调函数来捕获；

好处：解决了控制反转问题，解决了回调地狱问题，实现了链式调用；



1. Generator + Promise:

问题：需要自己写执行器；

好处：可以控制函数的执行，用同步的流程写异步，解决了控制反转问题；

```javascript
// 执行器
function run (gen) {
    const g = gen()
    function next(data){
        const res = g.next(data)
        if(res.deno) return res.value
        res.value.then(data => next(data))
    }
    next();
}
// 结合generator调用
run(
    function* () {
        const res1 = yield // 异步操作
        // 操作res1...
    }
)
```



5. Async/Await：

```javascript
async function createFlow(){
    const data = await new Promise();
}
// ES2017加入了async await可以帮我们封装好了方法。
// 它在请求成功后会再一次进入async函数中, 回到上次await暂停的位置将返回值传入并再次执行下去,不需要我们手动调用了
```

问题：await将异步代码改成同步代码，如果多个异步操作没有依懒性而使用await会导致性能上的降低；

好处：代码清晰，解决Generator + Promise需要自己写执行器的问题；
