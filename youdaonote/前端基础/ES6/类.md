# 类在js里本质上ES6类本质上还是基于原型的伪类，是一种特殊的函数，很大程度上是基于既有原型机制的语法糖。



1. 它里面的constructor关键字用于在类定义块内部创建类的构造函数，但new关键词创建类的新实例时会自动调用这个函数。

1. 类在使用new调用时会被当场构造函数，类中定义的constructor不会被当成构造函数，对他使用instanceof操作符时会返回false。

1. static关键词可以在类上定义静态方法，这些方法通常用于执行不特定于实例的操作，也不要求存在类的实例。

1. 在静态方法中，this引用于类自身。

1. 类定义语法支持在原型和类本身上定义生成器方法，所以可以通过添加一个默认的迭代器，把实例变成可迭代对象。



# ES6定义类：

```javascript
class ClassName1 {
    constructor(arg){
        this.arg = arg
    }
    Fun1(){} //定义原型上的方法
    static Fun2(){} //定义静态方法
    set Fun3(value){} //自定义一个获取的值
    get Fun3(){} //自定义一个得到的值
}
```



# 将实例变成可迭代对象：

```javascript
class Person {
  constructor() {
    this.nicknames = ['Jack', 'Jake', 'J-Dog'];
  }
  *[Symbol.iterator]() {
    yield *this.nicknames.entries();
  }
  /** 也可以只返回迭代器实例：
  [Symbol.iterator]() {
    return this.nicknames.entries();
  } */
}

let p = new Person(); 

for (let [idx, nickname] of p) {
 console.log(nickname);
}
```



# 注：

1. 类声明不会被提升；

1. 类声明中的代码都会自动运行在严格模式下；(不好的语法不能使用)

1. 调用类必须使用new；

1. 类中所有的方法都是不可枚举的；

1. 类中的方法不能用new调用的；

1. 在类的方法中重写类名报错；



## 类的继承：

### 1. 使用extend关键字，就可以继承任何拥有[[Construct]]和原型的对象，所以类也可以继承普通的构造函数。

```javascript
class Vehicle {}
function Person() {}

class Bus extends Vehicle {} // 继承类
class Engineer extends Person {} // 继承普通构造函数
```



### 2. 派生类的方法可以通过super关键字引用它们的原型。

```javascript
class Vehicle {
  constructor(licensePlate){
   this.licensePlate = licensePlate; 
  }

  static identify() {}
}

class Bus extends Vehicle {
  constructor(licensePlate){
    // 不要在super之前调用this 不然会报错
    super(licensePlate); // 他可以给手动是父类传参
  }

  static identify() { 
    super.identify(); // super也可以调用继承类上的静态方法
  } 
}
```



### 3. new.target保存通过new关键字调用的类或函数。

```javascript
class Vehicle {
  constructor() {
    // 实例化时检测new.target是不是抽象基类, 阻止抽象基类的实例化, 只允许被继承。
    if (new.target === Vehicle) {
      throw new Error('Vehicle cannot be directly instantiated');
    }
  }
}
```



### 4. 类混入

```javascript
// 辅助函数
function mix(BaseClass, ...Mixins) {
  return Mixins.reduce((accumulator, current) => current(accumulator), BaseClass);
}

let FooMixin = (Superclass) => class extends Superclass {
  foo() {
  console.log('foo');
  }
};
let BarMixin = (Superclass) => class extends Superclass {
  bar() {
  console.log('bar');
  }
};

// 混入
class Bus extends mix(FooMixin, BarMixin) {}
```
