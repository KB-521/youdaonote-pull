> 模块化主要是用来抽离公共函数，隔离作用域，避免变量冲突等。



1. IIFE：使用自执行函数来编写模块化。

特点：在一个单独的函数作用域中执行代码，避免变量冲突。

```javascript
(function() {
    return {
        data: []
    }
})()
```



1. AMD：使用requireJS来编写模块化。

特点：依赖必需要提前声明好。

```javascript
define("./index.js", function(code) {
    // code 就是index.js返回的内容
})
```



1. CMD：使用seaJs来编写模块化

特点：知道动态引入依赖文件

```javascript
define(function(require, expirts, modules){
    var indexCode = require("./index.js")
})
```



1. CommonJS：nodeJS自带的模块化

```javascript
var fs = require("fs")
```



1. UMD：兼容AMD，CommonJS 模块化语法。



1. webpack（require.ensure）：webpack 2.x 版本中的代码分割。



1. ES Modules：ES6引入的模块化，支持import来引入另一个js。

导出：

```javascript
exprot {obj as XXX,a,b,c}; //导出obj并重命名为XXX,a,b,c
exprot default function XXX(){}; //默认导出
```



导入：

```javascript
<script type = "module">
    import {XXX as obj,a,b,c} from './XXX.js';
    //导入XXX并重名为obj,a,b,c
    import * as XXX from './XXX.js'; 
    //导入全部的导出为 XXX对象
    import XXX from './XXX.js'; 
    //导入默认导出,并命名为XXX
</script>
```
