1. react v16 版本前的更新都是从root开始的，vue是以组件粒度更新的。

1. requestIdleCallback( callback, { timeout } ): 

1. 作用：在浏览器有空余的时间，浏览器就会调用requestIdleCallback里的回调。

1. react requestIdleCallback五个优先级：

1. Immediate: -1 需要立即执行；

1. UserBlocking: 250ms  超时时间250ms，一般指用户的交互；

1. Normal: 5000ms  超时时间5s，不需要直观立即变化的任务，比如网络请求；

1. Low: 10000ms  超时时间10s，肯定要执行的任务，但是可以放到最后处理；

1. Idle: 一些没有必要的任务，可能不会执行；
