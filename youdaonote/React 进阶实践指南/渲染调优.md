1. 异步渲染：Suspense；

1. 原理：Suspense在执行内部可以通过 try{}catch{} 方式捕获异常，这个异常一般是一个 Promise，可以在这个 Promise 中进行数据请求工作，Suspense 内部会处理这个 Promise，Promise 结束后，Suspense 会重新 render 把数据渲染出来。

1. 动态加载（懒加载）：React.lazy；

1. lazy 用 Prmose 模拟了一个动态的组件请求过程。下一次渲染直接渲染这个组件，所以是 React.lazy 利用 Suspense 接收 Promise， 执行 Promise，然后再渲染这个特性做到动态加载的。

1. React.lazy + Susponse模拟异步组件功能：

```
import { Suspense } from "react"

/**
 * @param {*} Component  需要异步数据的component 
 * @param {*} api        请求数据接口,返回Promise，可以再then中获取与后端交互的数据
 * @returns 
 */
function AysncComponent(Component, api) {
  const AysncComponentPromise = () => new Promise(async (reslove) => {
    const data = await api()

    reslove({
      default: (props) => <Component rdata={data} {...props} />
    })
  })

  return React.lazy(AysncComponentPromise)
}

/* 数据模拟 */
const getData = () => {
  return new Promise((reslove) => {
    setTimeout(() => {
      reslove({
        name: "alien",
        asy: 'let us learn React!'
      })
    }, 1000)
  })
}

/* 测试异步组件 */
function Test({ rdata, age }) {
  const { name, say } = rdata
  return (
    <div>
      <div> hello , my name is {name} </div>
      <div>age : {age} </div>
      <div> i want to say {say} </div>
    </div>
  )
}

/* 父组件 */
export default class Index extends React.Component {
  LazyTest = AysncComponent(Test, getData)

  render() {
    const { LazyTest } = this
    return (
      <div>
        <Suspense fallback={<div>loading...</div>}>
          <LazyTest age={18} />
        </Suspense>
      </div>
    )
  }
}
```
