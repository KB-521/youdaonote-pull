接口：

```typescript
// 在ts中使用接口(interface)对类的一部分进行抽象外,也可以用于对[对象的形状]进行描述
interface Person {
    readonly id: number; // readonly:第一次给对象赋值的时候才能初始化。
    name: string; // 确定属性: 必需在对象中出现。
    age?: number; // ?: 这个属性在对象中是可选的,可以不存在。
    [propName: string]: string | number;// 接口允许有任意的属性。
}
let tom: Person = {}
```

注: 接口定义了任意属性后，那么确定属性和可选属性必需是他的子类型。



数组：

```typescript
let arr: number[] // 使用any[]描述表示允许任意类型
let arr: Array<number> //泛型
interface IArguments{ // 用接口描述, 接口一般用来描述类数组
    [index: number]: any;
    length: number;
    callee: Function;
}
// 注:ts会把数组的一些方法的参数也进行限制,如push()。
// ts内置了一些常用的接口定义, IArguments, NodeList, HTMLCollection。
```
