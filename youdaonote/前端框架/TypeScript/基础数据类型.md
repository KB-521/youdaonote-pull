原始数据类型：

```typescript
let isDone: boolean // 布尔值
let isDone: string //字符串
let isDone: number // 数值
let isDone: void // 空值 (它只能被赋值 undefined和null,而且不能赋值给其他类型)
let isDone: undefined || null //它们是所有类型的子类,可以赋值给其他类型。
```

注：new出来的都是构造函数，返回出来的是对象，不是对应的类型。



任意值：

```typescript
let isDone: any
// 任意值上可以访问任何的属性，也允许调用任意的方法。
// 可以理解为声明一个任意值后,对他的任何操作,返回内容类型都是任意值。
```

注: ts有类型推论，但他在声明的时候没有赋值，不管之后有没有赋值，都会被推断成any类型二不会被类型检查。



联合类型：

```typescript
let isDone: string|number 
// 允许类型是string和number,但不能是其他类型
```

注: 当ts不能明确联合类型的变量是哪个的时候(如函数引用值中),我们只能访问两个类型共有的方法或属性;

联合类型被赋值的时候,会根据类型推论的规则判断出一个类型,就可以使用对应的方法或属性了。
