类别别名(常用于联合类型)：

```typescript
type Name = string
type NameReslover = () => string
type NameOrReslover = Name | NameReslover
let getName: NameOrReslover
```



字符串字面量类型：

```typescript
type EventNames = 'click' | 'scroll' | 'mousemove'
function handleEvent(ele: Element, event: EventName){}
// event就只能取EventNames所规定的三个之一
```



元组：

```typescript
let tom = [string,number] = ['Tom', 25]
// 注: 当赋值或访问一个已知的元素时就可以得到正确的类型。
// 也可以只赋值一项,但要是直接对元组类型的变量进行初始化或者赋值时,必须提供元组类型中指定的项。
// 当添加越界元素时,类型必须为元组中每个类型的联合类型。
```



枚举：

```typescript
enum Days {Sun, Mon, Tue, Wed, Thu= 7, Fri= <any>"S", Sat = "blue".length}
// 它们会默认赋值0~6(Days.sum === 0),可以手动修改,最好不要修改成一样的。
// 可以用类型断言修改成非数字。
// 可以是个计算所得项,但后面不能是未手动赋值的项。

const enum Directions {Up, Down, Left, Right} // 常数枚举
// 它会在编译阶段被删除,而且不能包含计算成员
declare enum Directions {Up, Down, Left, Right} //外部枚举
// 也可以同时使用外部常数枚举 declare const enum
```
