1.创建项目

2.下载babel和live-server

```javascript
npm install @babel/cli @babel/core @babel/preset-env @babel/preset-react --save-dev
npm isstall live-server -g //本地服务器相关
```

3.配置.babelrc文件

```javascript
{
    "presets": ["@babel/preset-env","@babel/preset-react"]
}
```

4. 创建运行文件夹以及index.html并引入react

5.创建script命令 

```javascript
"scripts": {
    "babel": "babel"
}
```

6. 控制台运行

```javascript
live-server public/ //开启本地服务器
npm run babel -- src/app.js -o public/js/app.js -w
//将scr下的js文件用babel编译到运行文件夹下 并监听
```
