React 可以将一些简短、独立的代码片段组合成复杂的 UI 界面，这些代码片段被称作“组件”。

创建React类组件：

```javascript
class 组件名 extends React.Component {
    render() {
        //return JSX语法
        return (<div></div>)
    }
}
// 注: 1.组件名必需要大写开头,与HTML中的标签区分开来
// 2. 每个组件都要继承React中的Component方法
```



创建React函数组件：

```javascript
const 组件名 = (props) => {
    //return JSX语法
    retrun (<div>
        {props.jsx} //可以渲染通过props传入的jsx
        {props.children} 
        //特殊方法,可以渲染dom,使用组件中传入
    </div>)
}
// 函数组件优点: 1.运行速度比类组件更快。2.可读性更高。
// 函数组件缺点: 1.无法使用state。2.没有生命周期。
```



使用组件：

```javascript
// JSX中:
<div>
    <组件名 jsx={jsx语法}/>
    <组件名>dom</组件名>
</div>
// reader函数里中:
ReactDOM.render(<MyApp />, app)
```
