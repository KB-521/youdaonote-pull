运动：

```javascript
.hide()/show(); //绑定元素隐藏/展示
.slideDown()/.slideUp(); //绑定元素从上往下进入/从下往上隐藏
.slideToggle(); //自动判断进入还是隐藏
//可以填入执行时间(毫秒)以及函数(执行时间结束自动执行)
```



淡入/淡出：

```javascript
.fadeIn()/fadeOut(); //绑定元素淡入/淡出
.fadeToggle(); //自动判断淡入还是淡出
//可以填入执行时间(毫秒)、速度函数以及函数(执行时间结束自动执行)
.fadeTo(opacity); //自定义透明度
//可以填入执行时间(毫秒)以及函数(执行时间结束自动执行)
```



动画：

```javascript
.animate(Obj,time,Easings,Fun); //设置动画
//Obj:动画完成后属性的位置对象(属性名:属性值)
//time:动画完成时间(毫秒),选填
//Easings:速度函数(插件Easings.js),选填
//Fun:动画完成后立即执行的函数,选填

.stop(Boolean1,Boolean2); //动画暂停
//Boolean1:是否取消动画队列(默认false)
//Boolean2:是否立即执行完当前动画(默认false)
```
