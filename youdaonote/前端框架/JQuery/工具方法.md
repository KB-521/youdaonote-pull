实例方法：定义在JQuery原型上的方法    $(dom).方法()；

工具方法：定义在JQuery函数上的方法    $.方法()；

许多实例方法都是基于工具方法封装的；



常用方法：

```javascript
$.type(); //检测填入数据的类型
$.trim(str); //去除str首尾的空格
$.makeArray(Obj); //能把类数组Obj变成数组
$.inArray(str，array); //能检测str在数组array的位置,如果没有该数据返回-1
//可以再填入一个num,函数将会从num处开始查找str
$.each(data,Fun); //遍历data{数组Fun(index,ele),对象Fun(name,value)}
$.merge(arr1,arr2); //将arr2拼接到arr1中
//类数组也可以拼接,返回什么类型看arr1是数组还是类数组
$.noConflict(); //提交$的权限,和其他的插件起冲突时使用
//可以填入true将JQuery的权限也提交出去,可以使用变量接受权限
//如果引入两个不同版本的JQuery,使用方法会将后引入的权限提交出去
$.data($(dom),'Name'); //提取出dom上存储的数据Name
//可以在填入一个数据,会用填入的数据覆盖之前的
//Name处也可以填入对象,会用对象覆盖之前全部的数据
```



高级方法：

```javascript
$.extend(obj1,obj2,obj3,······); //合并对象到obj1
//默认浅拷贝,开头可以填入ture进行深度拷贝
//如果只填入一个Obj,那么就会把Obj拷贝到$中(工具方法原理)
//jq拷贝源码必需背下

$.fn.extend(Obj); //合并对象到obj
//fn = prototype
//会把Obj拷贝到原型中(实例方法原理);
//默认浅拷贝,开头可以填入ture进行深度拷贝

var cb = $.Callbacks(); //向列表添加回调函数
//可以填入'once': 只能fire一次
//'memory': fire后add会自动执行回调函数
//'unique': 去除重复的函数
//'stopOnFalse': 如果回调函数返回false,则停止fire
cb.add(Fun); //将函数添加到cb内,可以填入多个,也可以填入数组
cb.fire(); //执行cb中的全部方法;

var dtd = $.Deferred(); //延迟执行
dtd.resolve(); //修改为成功状态
dtd.reject(); //修改为失败状态
dtd.notify(); //修改为进行中状态
dtd.done(Fun); //成功状态时执行的函数
dtd.fail(Fun); //失败状态时执行的函数
dtd.progress(Fun); //进行中状态时执行的函数
```
