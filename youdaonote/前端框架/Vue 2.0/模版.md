用vue对象定义的标签就是模版；

模版有两种：HTML模版、template模版；

{{ }}：里面可以写简单的js表达式(变量，三步运算符，函数执行)；

```javascript
<v-bind:标签属性="js表达式">
//可以将标签属性用vue中的变量或者函数绑定;
<v-once> //标签数据绑定后就不会改变了;
<v-html=:"js表达式"> //不推荐使用
//将表达式中的东西视为html标签绑定而不是字符串;
```



模版到真实html过程

模版 -》编译 -》ast(一种结构) -》绑定数据 -》render -》虚拟dom -》真实HTML；
